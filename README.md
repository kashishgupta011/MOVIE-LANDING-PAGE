# 🎬 Movie Landing Page

A modern and responsive movie landing page built using **HTML, CSS, and JavaScript**.  
The project features a cinematic design with dynamic backgrounds, interactive movie cards, movie navigation, automatic transitions, and search functionality.

## ✨ Features

- 🎥 Dynamic hero section
- 🖼️ Movie-specific background images
- 🎬 Interactive movie cards
- ⬅️➡️ Previous and next movie navigation
- 🔄 Automatic movie transitions
- 🔎 Movie search functionality
- 📱 Responsive design
- ✨ Hover effects and smooth animations
- 🎞️ Dynamic movie title and description

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. For the best development experience, use the Live Server extension in VS Code.
